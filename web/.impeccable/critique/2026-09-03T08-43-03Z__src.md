## 设计独特性判定

**判定：category-interchangeable（品类可互换）。** 把 logo 换成任何一个 SaaS 后台的名字，没有一页会让人察觉违和——这是一套"用 Tailwind 默认零件拼出来的运维后台骨架"，不是"为 Klaw 专门设计的工作台"。

**LLM 评审**：slop 清单逐项命中——icon-in-tinted-circle 磁贴（NetworkPage.tsx:202-239、StoragePage 同构）、6 卡/5 卡 stat 卡墙（Backups/Tenants/Monitoring）、badge 汤（ServicesPage 一页 5 种 hue）、emoji 当图标（ClusterDashboard.tsx:78-82、ToastContext、DiagnosticsPage）、十种 hue 的 Tailwind 原色约 260 处 bg-* / 180 处 text-*，语义 token（success/warning/danger）只有半数页面在用。最有产品性格的 2 处：MonitoringPage 告警规则卡、SosCallPage 的无障碍自觉。

**确定性扫描**（detect.mjs，退出码 2，12 条）：border-accent-on-rounded ×5（ServiceDetailDrawer:378、NetworkPage:252、ServicesPage:166、StoragePage:276、ServicesPage 2.tsx:166）、gray-on-color ×6（TenantsPage:230/330 各×2、ServicesPage:272、ServicesPage 2.tsx:268）、side-tab ×1（MonitoringPage:238）。检测器抓到了 LLM 评审漏掉的 4 个文件的装饰性 border-b-2；ServicesPage 2.tsx 为未跟踪重复文件、不在构建内，其 2 条按无效处理。降级声明：本机 detect.mjs 走正则回退，12 条是欠报下限而非全集。

## 总体印象

数据层做厚之后，页面"信息很满、语言很平"——数据是 K8s 的，皮肤还是 Tailwind 默认零件箱的。比风格更急的是三处"工具在说谎或自残"的功能性 P0：假进度条、被裁掉的删除按钮、紧急页死路。最大机会：以告警规则卡为原点收束一套 Klaw 设计语言，同时清掉这三处。

## 做得对的

1. **MonitoringPage 告警规则卡**（MonitoringPage.tsx:169-200）：等宽条件表达式 + border-l-4 严重度色条 + 窗口时长 badge——为"运维逐字读规则本体"这个真实动作排版，应作为全站设计语言的原点。
2. **"新派"页面架构**（ServicesPage 代表）：共享 Selector/RefreshButton + 查询参数同步 URL + Toast——Operate 工具的正确方向，应反向推广。
3. **SOS 页的无障碍自觉**（SosCallPage.tsx:35/115/125）：全站 4 处 aria-label 中 3 处在此，缺的是推广到其余所有 icon-only 按钮的纪律。

## 优先问题

**[P0] Pods 表格横向溢出，删除按钮被裁出可视区**
- 为什么：9 列 px-6 py-4 表格总宽 1177px > 容器 1121px（DOM 实测），56px 溢出恰好裁掉最右操作列——用户以为没有删除功能。/nodes 的 6 处 text-overflow 佐证溢出是系统性问题。
- 修法：列优先级（窄屏隐藏次要列）、操作列 sticky right-0、overflow-x-auto + 阴影提示可横滚。
- 建议命令：/impeccable layout

**[P0] SOS 紧急呼叫页布局崩坏 + 错误态死路**
- 为什么：情绪权重最高的页面完成度最低——双导航、min-h-screen 导致挂断/静音按钮被视口裁一半、错误态"出错了 · Permission denied"无重试无返回。peak-end 定律下，最需要安心的时刻制造了恐慌。
- 修法：SOS 路由脱离 App shell 渲染为全屏 overlay；控制条 sticky bottom-0；error 态给"重试 + 返回首页"两个出口。
- 建议命令：/impeccable harden

**[P0] 仪表盘在说谎：节点就绪条恒满宽**
- 为什么：`w-[${...}%]` 动态类插值 Tailwind JIT 编译不到，进度条恒 100%——1/3 节点 NotReady 时总览仍全满。同族：Toast 动画类全无效（无 tailwindcss-animate 插件）、?theme=dark 深链与 App state 脱钩。
- 修法：改 style={{width}}；Toast 动画或补插件或删类；深链初始化 theme state。
- 建议命令：/impeccable polish

**[P1] AI slop 根因：设计语言未专属化**
- 为什么：十种 hue 原色、emoji 图标、tinted 磁贴、stat 卡墙、badge 汤、装饰性 border-b-2（检测器佐证 ×5）——任何产品都能原样套用这套 UI，slop 是结构性的。
- 修法：/impeccable shape 先定"高密度运维终端"方向 → extract 抽语义 token 与共享组件 → emoji 换 lucide 图标、stat 卡墙逐页重估。
- 建议命令：/impeccable shape（随后 extract）

**[P1] 深色模式对比度坍缩**
- 为什么：Tenants/Backups 整组 stat 标签与详情字段 text-gray-500 无 dark 变体（≈3.9:1，fail AA）；Monitoring severity 彩字同病；嵌套子卡深色与外层同色、层级坍缩；检测器另报 6 处 gray-on-color。
- 修法：每个 text-gray-* 强制 dark: 配对（eslint-plugin-tailwindcss 规则）；深色嵌套卡 gray-900 外层 + gray-800 内层。
- 建议命令：/impeccable polish
