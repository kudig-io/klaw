模块以 Kubernetes Operator 为核心：`controllers/` 中的 EtcdBackup/EtcdRestore/EtcdBackupSchedule Reconciler 监听 `api/v1alpha1` 定义的 CRD 并驱动底层快照与对象存储（S3/OSS）操作；`backend/` 提供独立 Gin REST API，供外部系统或 Web UI 直接调用；`web-ui/` 通过 Nginx 反向代理访问该 API 展示仪表盘与表单；`charts/etcdguardian` 与 `config/` 下的 Deployment、Service、RBAC、NetworkPolicy、Prometheus/Grafana 配置共同构成部署产物，由 `cmd/manager` 启动 Operator 进程、`cmd/cli` 提供命令行工具。前后端与 Operator 通过同一组 CRD 契约解耦：Operator 负责状态机推进，API/UI 负责触发与可视化。
