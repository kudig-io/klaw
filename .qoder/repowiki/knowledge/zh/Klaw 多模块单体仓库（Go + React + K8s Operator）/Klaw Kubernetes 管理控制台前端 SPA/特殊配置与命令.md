开发命令：`npm run dev` 启动真实后端代理模式（代理 `/api` → `http://localhost:8080`），`npm run dev:mock` 通过 `VITE_USE_MOCK=true` 启用 MSW Mock 模式；构建命令：`npm run build`（生产）、`npm run build:test`（test 模式）；测试命令：`npm run test`（watch）、`npm run test:run`（单次运行）、`npm run test:coverage`（覆盖率报告）、`npm run test:ui`（交互式 UI）；项目根目录提供 `test.sh` 脚本封装 all/unit/integration/coverage/ui/watch 等子命令。
