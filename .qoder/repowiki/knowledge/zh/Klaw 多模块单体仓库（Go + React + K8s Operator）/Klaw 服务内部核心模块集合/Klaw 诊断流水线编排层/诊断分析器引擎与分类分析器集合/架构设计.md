模块以 interface.go 中定义的 Analyzer 接口和 BaseAnalyzer 基类为核心抽象，所有具体分析器通过嵌入 BaseAnalyzer 复用 name/description/category/modes/deps 等元数据。
- registry.go 实现 Registry：维护 analyzer map，提供 Register/Get/List/ListByCategory/ListByMode 等查询，以及 ExecuteAll/ExecuteByCategory/ExecuteByMode/ExecuteByNames 等执行入口；executeAnalyzers 内部对 analyzers 做拓扑排序（sortByDependencies）并串行执行，同时支持 context 取消与耗时统计，CollectIssues 用于汇总结果。
- 各子目录（kernel、kubernetes、system、security、network、process、runtime、servicemesh、log）按领域划分分析器包，每个包内一个文件对应一类检查（如 kernel/kernel.go 中的 PanicAnalyzer/OOMAnalyzer 等），并在包级 init() 中调用 analyzer.Register 完成自动注册。
- 依赖方向单向：分析器只依赖 analyzer 顶层的 Analyzer/BaseAnalyzer/Registry 和 types.DiagnosticData，不反向依赖 registry。
- 执行模式通过 SupportedModes 声明 ModeOffline/ModeOnline，Analyze 中通过 data.HasK8sClient() 与 data.GetRawFile(...) 区分在线 API 与离线日志两种数据源。
