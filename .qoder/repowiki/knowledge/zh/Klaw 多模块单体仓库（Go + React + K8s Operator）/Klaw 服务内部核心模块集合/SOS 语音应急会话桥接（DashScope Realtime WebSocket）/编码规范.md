- 对外部可替换依赖（DashScope 拨号、诊断流水线）通过包级变量（`Dial`、`RunDiagnosis`）暴露，便于测试时注入假实现。
- WebSocket 写操作统一加锁（`wmuB`/`wmuU` 分别保护浏览器与上游连接）并设置 `writeWait` 写超时，避免并发写入竞态。
- 上游 JSON 事件统一经 `TranslateUpstream` 按 `type` 字段分派到文本帧、PCM 音频或工具调用三类输出，保持事件处理集中化。
- 工具定义采用 OpenAI Realtime 兼容的 `ToolDefinition` 结构体声明，参数 schema 通过 `obj(props, required)` 辅助函数构造，再以 switch 分发执行。
- 长文本输出统一经 `truncate` 截断（日志 8000 字符、事件消息 200 字符、诊断详情 300 字符），控制下游传输体积。
- 会话生命周期通过 `closeOnce` + `closed` channel 保证浏览器与上游连接仅关闭一次，并在空闲超过 `idleTimeout` 时主动断开。
