模块由两个子包组成：`internal/metrics` 仅包含 `collector.go`，定义 `Collector` 结构体及其收集的 `ClusterMetrics`、`NodeMetricsSummary`、`PodMetricsSummary`、`ResourceMetrics`、`EventMetric` 等数据模型，通过 `kubernetes.Manager` 获取客户端并调用 CoreV1 API 拉取 Node/Pod/Events 列表；`internal/monitoring` 包含 `manager.go` 和 `service.go`，其中 `Manager` 是轻量级监控管理器（每 10s 轮询集群节点状态并直接发送告警），`Service` 是更完整的监控服务，组合 `metrics.Collector` 与 `chart.Generator`，维护每个集群的指标历史（最多 100 条，使用 `sync.RWMutex` 保护），并通过三个 goroutine 分别执行指标收集（30s）、图表发送（5min）和告警检查（10s）。依赖方向单向：`monitoring` 依赖 `metrics` 和 `kubernetes`，两者均不反向依赖上层。
