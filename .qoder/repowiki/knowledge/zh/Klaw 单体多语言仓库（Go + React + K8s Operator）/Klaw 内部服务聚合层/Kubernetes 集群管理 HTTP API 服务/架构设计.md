模块以 `server.go` 中的 `Server` 结构体为聚合中心，持有 kubernetes.Manager、monitoring.Service、alerting/backup/tenancy/automation Manager、audit.Logger、kubernetes.Resources、metrics.Collector 等内部依赖；`NewServer` 构造时初始化 SQLite 存储（`data/klaw.db`）与各 Manager，并调用 `SetupRoutes` 注册所有 `/api/*` 路由。请求处理按业务域拆分到独立文件：`alerting.go`（告警规则 CRUD/评估/历史）、`backup.go`（备份 CRUD/摘要）、`tenancy.go`（租户与用户管理 + 审计日志查询）、`analysis.go`（Pod/RBAC 分析）、`automation_api.go`（脚本编排与网络/存储分析）、`diag.go`（诊断入口）。中间件链在 `Start` 中组合为 metrics → CORS → auth → deprecation → router，其中 `deprecationMiddleware` 对旧版 `/api/`（非 `/api/v1/`）自动附加 Deprecation/Sunset/Link 响应头。`unified_v1.go` 通过 `setupUnifiedV1Routes` 复用同一组 handler 同时挂载到 `/api/v1/*`，实现双版本兼容；另提供统一的 `/api/v1/clusters/{cluster}/resources/{kind}` 泛型资源接口，将 Pod/Deployment/Service/Node/Event/ConfigMap/StatefulSet/Ingress/Namespace 统一映射为 `UnifiedResourceInfo`。SPA 静态文件由末尾的 `PathPrefix("/")` 兜底返回 `./web/dist/index.html`。
