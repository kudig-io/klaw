本模块作为 klaw 诊断系统的顶层编排器，通过 pipeline.go 的 RunOnlineDiagnostics 按固定阶段串联各子模块：collector 负责 online/offline 两种数据源采集 → analyzer 引擎调度 kernel/kubernetes/system/security/network/process/runtime/servicemesh/log/ebpf 等多维度分析器 → rules_engine 将 YAML 规则转换为 Issue → rca/autofix 基于问题现象映射根因并执行安全自愈命令 → ai_assistant 调用 OpenAI 兼容 API 生成结构化修复建议 → reporter 输出 JSON/HTML/SARIF/Text/Grafana 多格式报告；import.go 通过空白导入触发各 analyzer 子包的 init() 完成插件式注册，使新增分析器无需修改调用方即可被默认执行；types 包集中定义 DiagnosticData、Issue、Severity 等跨子模块共享的核心结构体，所有子模块围绕这些类型进行数据流转；supporting_utils（history/notifier/cost/scanner/tui）作为横切能力在各阶段按需注入。
