- 所有对外暴露的结构体通过 `NewXxx` 构造函数初始化，字段以指针或 map 形式注入依赖（如 `*kubernetes.Manager`、`*dingtalk.Client`、`*feishu.Client`）。
- 周期性任务统一使用 `time.NewTicker` + `select` 循环模式启动 goroutine，并在 defer 中停止 ticker。
- 共享状态（`alerts`、`metricsHistory`）通过 `sync.RWMutex` 读写保护，读操作使用 `RLock`/`RUnlock`，写操作使用 `Lock`/`Unlock`。
- 错误处理采用 `fmt.Errorf("failed to ...: %v", err)` 包装原始错误并返回，而非 panic。
- 告警 ID 通过 `clusterName`、时间戳格式 `20060102150405` 拼接生成，确保唯一性。
