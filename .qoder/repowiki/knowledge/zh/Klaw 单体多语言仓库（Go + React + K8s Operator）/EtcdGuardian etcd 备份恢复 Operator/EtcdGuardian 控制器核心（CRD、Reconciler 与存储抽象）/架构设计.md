模块按 Kubernetes Operator 标准分层组织：
- `api/v1alpha1`：基于 kubebuilder/controller-runtime 声明 CRD 类型（EtcdBackup、EtcdRestore、EtcdBackupSchedule），通过 `GroupVersion=etcdguardian.io/v1alpha1` 注册并生成 DeepCopy。
- `controllers/`：每个 CRD 对应一个 Reconciler，遵循 `Fetch → Finalizer 检查 → 删除处理 → Phase 状态机驱动业务` 的统一流程；以 `Status.Phase` 字段推进备份/恢复生命周期（Pending→Validating→Preparing→Snapshotting→Uploading→TriggeringVelero→Completed/Failed）。
- `pkg/snapshot`：提供 SnapshotEngine，根据 BackupMode（Full/Incremental）执行 etcd 快照。
- `pkg/storage`：定义 `Storage` 接口并通过 `NewStorage` 工厂按 Provider（S3/OSS/GCS/Azure）返回具体实现（s3.go、oss.go），控制器仅依赖抽象。
- `pkg/validation`：对已上传快照进行校验，输出 ValidationResult。
- `pkg/metrics`：暴露 Prometheus 指标。
依赖方向单向：controllers → api/types + pkg/*，pkg 之间无循环，storage 不反向引用 controllers。
