模块以 `main.go` 为唯一入口，使用 `gin.Default()` 启动 HTTP 服务器并挂载全局中间件：CORS、自定义 `middleware.Logger`（记录状态码/耗时/IP/方法/路径）和 `middleware.Recovery`（捕获 panic 返回 500）。所有业务路由统一注册在 `/api/v1` 分组下，按资源划分为 `backup.go`、`restore.go`、`schedule.go`、`health.go` 四个 handler 文件，每个文件定义对应 JSON 结构体并提供 List/Create/Get/Delete 等标准 REST 处理器；当前所有处理器均返回 Mock 数据，尚未接入真实 etcd 或存储层。`service/` 目录为空，预留用于后续业务逻辑下沉；`config/` 目录存在但未见配置文件，依赖通过 `go.mod` 声明（仅 gin 及其 CORS 扩展）。
