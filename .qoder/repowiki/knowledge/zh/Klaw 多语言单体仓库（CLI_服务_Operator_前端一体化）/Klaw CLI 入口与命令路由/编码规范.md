- 每个子命令以独立的 cobra.Command 变量定义并在 init() 中通过 rootCmd.AddCommand 注册，flag 通过全局 var + Flags.XxxVar 绑定。
- 子命令的 RunE 回调集中负责参数校验与调用对应 runXxx 函数，错误通过 error 返回而非直接 panic。
- server 启动流程采用“配置加载 → 组件构造 → 按需启用（dingtalk/feishu/events/openclaw）→ 启动 API → 信号监听”的顺序装配模式。
- 外部子系统通过构造函数注入依赖（如 k8sManager、monitoringService），避免在命令层直接耦合 internal 包细节。
