模块以 `main.go` 为唯一可执行入口，使用 spf13/cobra 构建根命令并注册 `version`、`server`、`diag` 子命令；当未传子命令时默认回退到 `server`。`cmd_server.go` 在 `runServer` 中按顺序装配内部子系统：加载 `internal/config`、初始化 `kubernetes.Manager`、构造 `monitoring`/`ops`/`messaging`（钉钉、飞书）/`events`/`openclaw` 等组件，并通过 `api.NewServer` 启动 HTTP API，配合信号监听实现优雅关停。`cmd_diag.go` 将诊断参数映射为 `diag.DiagnosisRequest`，调用 `internal/diag.RunOnlineDiagnostics` 执行 70+ 分析器，并以人类可读文本或 JSON 输出结果，可选启用 `internal/diag/ai` 生成摘要。依赖方向单向指向 `internal/*` 包，本目录仅承担命令行装配与参数解析，不包含业务逻辑。
