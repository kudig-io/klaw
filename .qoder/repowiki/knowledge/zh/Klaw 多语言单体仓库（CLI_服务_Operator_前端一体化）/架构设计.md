根目录作为多语言单体仓库的编排层：Go 代码集中在 `cmd/klaw` 入口，由根 `go.mod` 集中声明 k8s.io/client-go v0.28、klog、cobra、gorilla/mux、modernc/sqlite 等共享依赖，operator、klaw_service、etcd_backup_module、etcd_guardian_module 等子包均复用同一份版本约束；`Makefile` 提供统一的 build/dev/test/lint/docker/helm 目标，先并行构建 `web/` 前端产物再编译 Go 二进制；`Dockerfile` 采用三阶段构建（node:20 → golang:1.24 → alpine:3.20），将 web/dist、configs/、skills/ 与 klaw 二进制打包进单一镜像并以非 root 用户（uid 65532）暴露 8080 端口；`helm/klaw` 与 `deployment/` 目录分别提供 Helm Chart 与 Kind 本地集群部署方案，使 operator、klaw_service、etcd_backup_module、etcd_guardian_module 与 web_frontend 在同一镜像中协同运行。
