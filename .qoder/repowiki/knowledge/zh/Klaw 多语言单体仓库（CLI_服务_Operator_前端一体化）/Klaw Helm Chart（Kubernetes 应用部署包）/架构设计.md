Chart 遵循标准 Helm v2 结构：`Chart.yaml` 声明应用元信息；`values.yaml` 提供默认配置（镜像、资源、探针、安全上下文、RBAC、持久化等），`values-kind.yaml` 通过 `--values` 覆盖以适配 kind 本地开发环境。模板目录按资源类型拆分：`deployment.yaml` 挂载 ConfigMap（/app/configs）、PVC（/app/data）和 emptyDir tmp 卷，并通过 `checksum/config` 注解触发滚动更新；`configmap.yaml` 渲染非敏感配置；`secret.yaml` 渲染 API Token、AI 及第三方消息渠道密钥，支持通过 `existingSecret` 引用外部 Secret；`rbac.yaml`、`serviceaccount.yaml`、`service.yaml`、`pvc.yaml` 分别声明最小权限 RBAC、ServiceAccount、ClusterIP Service 和可选 PVC。所有命名、标签、选择器统一由 `_helpers.tpl` 中的 `klaw.name/fullname/chart/labels/selectorLabels/serviceAccountName/secretName` 辅助函数生成，确保多 Release 共存时名称不冲突。依赖方向单向：模板消费 values，不反向引用外部模块，charts 子目录为空预留子 chart 扩展点。
