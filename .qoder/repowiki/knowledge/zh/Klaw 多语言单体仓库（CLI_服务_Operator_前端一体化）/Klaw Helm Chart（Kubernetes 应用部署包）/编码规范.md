- 所有资源名称、标签、选择器均通过 `_helpers.tpl` 中的 `klaw.*` 辅助函数生成，避免硬编码 Release 名与 Chart 名。
- 可开关的资源（ServiceAccount、RBAC、Persistence）在 values 中以 `create/enabled` 布尔值控制，模板中使用 `{{- if }}` 条件渲染。
- 敏感信息集中放入 `secrets` 块并渲染为 Secret，非敏感配置放入 `config` 块并渲染为 ConfigMap，二者在部署模板中通过 `envFrom.secretRef` 与 `volumeMounts` 分别注入。
- 镜像 tag 优先使用 `.Values.deployment.image.tag`，未设置时回退到 `.Chart.AppVersion`，禁止直接使用 latest 镜像。
- Pod 安全采用最小权限模型：`podSecurityContext.runAsNonRoot=true`、`securityContext.allowPrivilegeEscalation=false`、`capabilities.drop=[ALL]`、`readOnlyRootFilesystem=true`。
