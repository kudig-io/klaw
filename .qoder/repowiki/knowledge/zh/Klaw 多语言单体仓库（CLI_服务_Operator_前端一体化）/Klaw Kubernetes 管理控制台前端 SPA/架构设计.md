模块采用标准 Vite + React SPA 结构：入口 `src/main.tsx` 通过 `BrowserRouter` 与 `ToastProvider` 包裹根组件；`src/App.tsx` 集中定义 Dashboard、Backups、Tenants、Deployments、Services、Pods、Nodes、Monitoring、Diagnostics、SOS 等路由与导航栏，并通过 `localStorage.USE_MOCK` 切换 Mock 模式。数据层集中在 `src/lib/api.ts`，创建两个 axios 实例 `api`（baseURL `/api`）和 `v1Api`（baseURL `/api/v1`），按领域拆分为 `clusterApi`、`podApi`、`nodeApi`、`eventApi`、`monitoringApi`、`deploymentApi`、`serviceApi`、`analysisApi`、`alertingApi`、`backupApi`、`tenancyApi`、`auditApi`、`unifiedClusterApi`、`unifiedResourceApi` 等命名空间对象，所有后端响应数据结构以 TypeScript interface 在文件内集中声明。UI 层按职责分层：`src/pages/` 为页面级组件，`src/components/` 为可复用组件（ClusterSelector、NamespaceSelector、RefreshButton、ServiceDetailDrawer、SosFloatingButton），`src/contexts/ToastContext.tsx` 提供全局 Toast 通知，`src/hooks/useSosSession.ts` 封装 SOS 会话逻辑，`src/worklets/pcm-processor.ts` 使用 Web Audio Worklet 处理 PCM 音频。构建配置在 `vite.config.ts` 中设置端口 3000、`/api` 代理到 `http://localhost:8080`、别名 `@` 指向 `src`，产物输出至 `dist/`。测试体系基于 Vitest + jsdom，Mock 数据与处理器放在 `src/__tests__/mocks/`，通过 `public/mockServiceWorker.js` 注入 MSW worker，支持 `dev:mock` 脚本启动 Mock 开发环境。
