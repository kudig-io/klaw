- 结构化体统一使用 `json:` 和 `yaml:` 标签，便于序列化输出与配置读取。
- 不可变枚举类型（如 `Severity`、`DataMode`）通过自定义 `String()` / `EnglishString()` 方法提供多语言字符串表示，并实现 `json.Marshaler`/`Unmarshaler` 以支持双向 JSON 编解码。
- 对象构造采用构造函数模式（如 `NewDiagnosticData`、`NewIssue`），并通过链式方法（如 `WithRemediation`、`WithMetadata`）进行可选字段设置。
- 通过 `_ "package"` 空白导入触发包 init() 完成组件注册，避免调用方手动维护注册表。
- 敏感或运行时对象（如 `RawFiles`、`LogStreams`、`K8sClient`）在 JSON/YAML 中标记为 `-` 以排除序列化。
