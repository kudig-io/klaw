- 所有对外部 LLM 的调用都通过 `context.WithTimeout` 包裹，超时时间来自 `config.Timeout`，并在 defer 中 cancel。
- 本地化文案统一通过 `getLocalizedMessage(key)` 方法按 `config.Language`（zh/en）查表返回，缺省回退到英文键。
- LLM 响应解析采用 JSON 优先、中文键映射、纯文本降级的三级回退策略，确保对非规范输出具备鲁棒性。
- 配置字段使用 Go struct tag 标注 `env:"..."` 和 `default:"..."`，由 `LoadConfig()` 中的 `getEnv`/`getEnvInt`/`getEnvFloat` 统一读取。
- 新增 Provider 实现只需满足 `Provider` 接口并由 `Factory.CreateProvider()` 在 switch 分支中注册，保持扩展点开放。
- Prompt 构建时根据 `config.Language` 分支生成中英文版本，包括 system prompt、分析提示与摘要提示。
