- 每个平台子包通过实现 `messaging.Communicator` 接口的 Name/Start/Stop/SendMessage/RegisterHandler/IsHealthy 方法作为统一接入点
- 平台工厂遵循 `CommunicatorFactory` 接口，由 `Create(config interface{})` 进行类型断言后返回具体 Communicator 实例
- 错误处理采用结构化错误类型（StartError/StopError/SendError/MultiError），并在 Manager 层聚合多个平台的失败原因
- 平台配置使用 struct tag 同时支持 YAML 和 JSON 解析（如 `yaml:"enabled" json:"enabled"`）
- 对外发送消息统一通过 `messaging.Response` 结构体并按 `FormatType`（plain/markdown/json/table/image）分支处理
