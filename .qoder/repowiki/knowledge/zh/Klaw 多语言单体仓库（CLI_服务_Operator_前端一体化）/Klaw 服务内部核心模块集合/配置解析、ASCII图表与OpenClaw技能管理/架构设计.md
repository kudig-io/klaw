本模块由三个相互独立、职责单一的内部子包组成，依赖方向单向且清晰：
- `internal/config`：通过 `config.go` 中的 `Config` 聚合结构体（含 `KubernetesConfig`、`MessagingConfig`、`OpenClawConfig`、`ServerConfig`、`EventConfig`、`SOSConfig`）定义全局配置模型；`Load(path)` 负责读取YAML文件、反序列化为结构体并设置默认值（如端口8080、DashScope region/model/voice），再通过 `applyEnvOverrides` 用 `KLAW_*` 环境变量覆盖敏感字段。
- `internal/chart`：`generator.go` 中的 `Generator` 类型封装ASCII文本图表渲染，对外暴露 `GenerateClusterMetricsChart`、`GenerateNodeMetricsChart`、`GeneratePodMetricsChart`、`GenerateResourceUsageChart` 等便捷方法，内部统一通过 `generateChart` + `generateBarChart` + `generateTimeLabels` 绘制，使用 `█` 字符输出纯文本条形图，依赖 `internal/metrics` 获取指标数据。
- `internal/openclaw`：`manager.go` 中的 `Manager` 组合 `config.OpenClawConfig` 与 `kubernetes.Manager`，在 `NewManager` 中校验技能路径存在性；`GetSkills()` 递归遍历 `skillsPath`，将包含 `SKILL.md` 的子目录识别为可用技能；`ExecuteSkill` 预留命令执行接口。
依赖方向：openclaw → config + kubernetes；chart → metrics；config 无内部依赖，可被其他子包复用。
