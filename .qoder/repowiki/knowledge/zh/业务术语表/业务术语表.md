### Klaw
- 定义：Kudig-io 开发的 Kubernetes 智能运维助手项目，提供 Web UI、ChatOps、实时事件监控、诊断分析、备份恢复等完整运维能力。项目采用 Go + React 技术栈，支持钉钉/飞书双消息平台集成。
- 别名：Kubernetes 智能运维助手、klaw

### etcd-guardian
- 定义：独立的 etcd 备份管理工具，计划完全整合到 Klaw 项目中，实现 etcd 集群状态的统一管理和备份恢复功能。该模块已作为独立 go.mod 存在于 modules/etcd-backup/ 目录中。
- 别名：etcd backup、etcd-backup

### ChatOps
- 定义：通过聊天机器人（钉钉/飞书）执行运维命令的工作模式，支持在群聊中直接操作 Kubernetes 集群，包括查看状态、重启 Pod、扩缩容等常见运维操作。
- 别名：聊天运维、chat operations

### Watch 模式
- 定义：Kubernetes 事件监听的高级模式，相比传统轮询方式延迟从 30-60 秒降低到 < 1 秒，通过长连接实时接收集群事件变更，大幅减少 API 调用频率。
- 别名：watch mode、事件监听

### 多租户隔离
- 定义：Klaw 的多租户架构设计，通过创建独立的 Namespace、Quota、NetworkPolicy、RoleBinding 等资源实现租户间的资源隔离和权限控制。
- 别名：tenant isolation、namespace isolation

### 诊断流水线
- 定义：Klaw 的核心诊断能力，包含 70+ 个分析器（analyzer），涵盖 Kubernetes 控制平面、网络、存储、GPU、安全等多个维度的健康检查和故障诊断。
- 别名：diagnostic pipeline、analyzer pipeline

### Operator
- 定义：基于 Kubernetes controller-runtime 构建的自定义控制器，用于自动化管理 ClusterDiagnostic、NodeDiagnostic、Schedule 等自定义资源对象的生命周期。
- 别名：k8s operator、controller

### Helm Chart
- 定义：Klaw 的 Kubernetes 部署模板包，包含 deployment、service、configmap、secret、rbac 等所有必要的 YAML 模板，支持通过 values.yaml 进行参数化配置。
- 别名：helm package、chart

### P0/P1/P2 优先级
- 定义：项目改进的优先级分类体系：P0 表示生产阻塞级缺陷（如安全漏洞、构建失败），P1 表示生产就绪必需功能，P2 表示持续改进项。
- 别名：priority levels、issue classification

### Go 版本三处不一致
- 定义：项目中的版本管理问题：主模块 go.mod 声明 1.24.2、operator 使用 1.21、etcd-backup 使用 1.25，同时 Makefile 和 Dockerfile 还引用了 1.20，造成构建环境混乱。
- 别名：version inconsistency、toolchain mismatch
