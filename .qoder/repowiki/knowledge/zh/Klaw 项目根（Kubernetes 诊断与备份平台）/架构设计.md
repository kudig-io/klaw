根目录作为多语言单体仓库的编排层：Go 模块 `github.com/kudig-io/klaw` 是唯一的 Go 依赖入口，`cmd/klaw` 为应用入口；`web/` 子目录包含 React+Vite 前端，构建产物 `web/dist` 被 Docker 多阶段镜像复制到最终镜像中由 Go 后端静态托管。`Makefile` 提供统一的 build/dev/test/lint/docker/helm 目标，将前端 npm 构建与 Go 编译串联；`Dockerfile` 以 node:20-alpine → golang:1.24-alpine → alpine:3.20 三阶段构建，输出单二进制 klaw 进程。operator、etcd_backup_module、klaw_service、web_frontend、deployment、docs 等子模块均以该根 go.mod 为依赖边界，通过共享的 storage.Store、config.Config 等内部接口协作，最终由 Helm chart（`helm/klaw`）在 Kubernetes 上统一部署。
