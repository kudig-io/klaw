- 每个 handler 方法签名固定为 `(s *Server) handleXxx(w http.ResponseWriter, r *http.Request)`，并通过 `mux.Vars(r)` 提取路径参数。
- JSON 响应统一通过 `s.respondJSON` 或 `writeJSON` 发送，错误统一通过 `s.respondError` 返回 `{"error": ...}` 格式。
- 写操作成功后调用 `s.logAudit(r, domain, action, metadata, status, extra)` 记录审计日志，如 backup.create、tenant.update、tenant-user.delete 等。
- URL 查询参数采用 `r.URL.Query().Get(...)` 读取并按需解析（如 tailLines、limit），未提供时使用默认值。
- v1 版本路由通过独立的 `setupUnifiedV1Routes` 复用同一组 handler，避免重复实现，仅前缀从 `/api/` 变为 `/api/v1/`。
- handler 中对 K8s 资源的访问统一委托给 `s.resources` 或对应 Manager（alertingManager、backupManager、tenancyManager、automationManager），不在 handler 内直接操作 client-go。
