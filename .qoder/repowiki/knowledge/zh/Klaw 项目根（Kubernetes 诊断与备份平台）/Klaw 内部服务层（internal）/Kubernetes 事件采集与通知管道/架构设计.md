模块采用「事件源 + 管理器 + 通知器」三层结构：
- source.go 定义核心类型（Event、EventType、ResourceType、Severity）和 Source 接口，提供 BaseSource 基础实现（订阅/取消订阅、过滤器、并发安全的 emit），以及 Manager 统一管理多个 Source 的注册、启动与停止。
- kubernetes.go 实现 KubernetesSource，继承 BaseSource，通过 client-go 对 Events/Pods/Deployments 建立 Watch 流，将 corev1.Event 转换为统一 Event 并调用 emit 分发。
- notifier.go 实现 Notifier，依赖外部 messaging.Manager 将事件转发到钉钉等渠道，内置 RateLimiter（令牌桶）、EventAggregator（时间窗口聚合）和 EventDedup（滑动窗口去重）三个中间件。
依赖方向单向：kubernetes.go → source.go；notifier.go → source.go + internal/messaging；Manager 作为全局协调者持有所有 Source 引用。
