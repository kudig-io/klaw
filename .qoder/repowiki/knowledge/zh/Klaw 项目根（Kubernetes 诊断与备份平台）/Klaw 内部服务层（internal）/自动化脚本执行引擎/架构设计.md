模块以 `Manager` 为核心协调器，通过 `types.go` 定义 `Script`、`ScriptExecution`、`Statistics` 等数据结构以及 `ScriptType`（builtin/custom）和 `ExecutionStatus` 枚举。
- 脚本分发：`dispatch` 根据 `Script.Type` 路由到 `executeBuiltin`（builtins.go）或 `executeCustom`（manager.go），后者通过 `os/exec` 调用 bash 执行命令。
- 内置脚本：builtins.go 中以 switch-case 注册具体操作（清理 Evicted Pod、重启崩溃 Pod、按 CPU 阈值扩缩容 Deployment、备份 ConfigMaps、节点健康检查、批量更新镜像标签），全部通过注入的 `kubernetes.Interface` 客户端访问 API Server。
- 持久化：依赖 `storage.Store`，使用 JSON 序列化将 scripts 和 history 分别存于 `automation/scripts` 和 `automation/history` 两个键下；启动时加载，首次为空则写入默认脚本。
- 并发安全：所有读写共享状态（scripts、history）均通过 `sync.RWMutex` 保护，读方法用 RLock，写方法用 Lock。
- 历史管理：执行记录保留最近 1000 条，按时间倒序插入，并提供 `History` 和 `Statistics` 查询接口。
- 参数合并：`mergeParams` 将脚本级默认参数与调用时传入参数合并，覆盖同名键。
