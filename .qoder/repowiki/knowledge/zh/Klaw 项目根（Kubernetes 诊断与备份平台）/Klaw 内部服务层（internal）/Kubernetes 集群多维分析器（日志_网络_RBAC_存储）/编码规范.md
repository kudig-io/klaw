- 每个分析器都遵循 `type Analyzer struct { clientset kubernetes.Interface }` + `func NewAnalyzer(clientset) *Analyzer` 的构造模式，便于注入 mock 客户端进行测试。
- 分析入口统一命名为 `AnalyzeXxx(ctx context.Context) (*XxxAnalysis, error)`，返回包含计数、分组 map 和 `Timestamp time.Time` 的结构体。
- 资源列表方法拆分为独立的 `ListXxx(ctx)` 辅助函数，主 Analyze 方法内部复用这些列表方法，避免重复代码。
- 聚合结果中的 map 字段统一按命名空间/类型/状态等维度分组，键为空字符串表示集群级（如 namespace=""）。
- 错误处理统一使用 `fmt.Errorf("...: %w", err)` 包装底层 client-go 错误，保持错误链可追溯。
