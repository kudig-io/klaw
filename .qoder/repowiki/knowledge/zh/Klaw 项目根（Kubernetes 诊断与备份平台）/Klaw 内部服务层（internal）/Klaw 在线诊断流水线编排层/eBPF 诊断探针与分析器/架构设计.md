模块按功能划分为三个子包：
- `probe/`：定义跨平台抽象层，`types.go` 声明统一的事件类型（EventType、Event）、各域统计结构（TCPStats/DNSStats/FileIOStats）和 Config；`manager_linux.go` 使用 cilium/ebpf 实现真实探针生命周期（NewProbeManager/Start/Stop/Events），`manager_other.go` 在非 Linux 或无 cgo 环境下返回不可用错误，二者通过 Go build tag 隔离。
- `analyzer/`：每个领域一个 Analyzer（TCPAnalyzer、DNSAnalyzer、FileIOAnalyzer），均嵌入 `internal/diag/analyzer.BaseAnalyzer` 并通过 `init()` 在 `init.go` 中统一注册到上层 analyzer 注册表；`Analyze` 方法负责构造 probe.Config、启动探针、等待超时后读取统计并转换为 `types.Issue`。
- `bpf/`：预留存放 eBPF C 源码的位置（当前为空）。
依赖方向单向向下：analyzer → probe → cilium/ebpf，不与上层诊断框架耦合，仅通过 types 与 BaseAnalyzer 交互。
