模块由两个核心文件组成：`store.go` 定义 `Store` 结构体（内嵌 `*sql.DB` 与 `sync.Mutex`），通过 `NewStore(dbPath)` 初始化 SQLite 连接、自动创建目录、执行 `documents` 表及领域表的 DDL；`schema.go` 集中管理领域表（`alert_rules`、`alert_history`、`tenants`、`tenant_users`、`audit_logs`、`backups`）的建表语句与从旧版 JSON 文档到结构化表的迁移逻辑。依赖方向单向：`schema.go` 依赖 `store.go` 提供的 `GetJSON`/`db.Exec`，而 `store.go` 仅调用 `InitSchema()` 完成领域表初始化。读写路径上，`PutJSON` 使用互斥锁保证并发安全，`GetJSON` 返回 `(bool, error)` 以区分未命中与错误，`Delete` 直接按 namespace+key 删除。所有 SQL 使用 `modernc.org/sqlite` 纯 Go 驱动，无需系统 SQLite 库。
