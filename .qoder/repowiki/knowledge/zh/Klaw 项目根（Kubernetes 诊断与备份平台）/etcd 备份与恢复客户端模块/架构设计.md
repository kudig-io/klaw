本模块为独立 Go 包 `github.com/kudig-io/klaw/modules/etcd-backup`，由三个文件构成清晰分层：
- `types.go`：定义所有数据模型（BackupPhase、RestorePhase、StorageProvider、BackupSpec、Backup、Restore、Schedule、Summary 等）及 JSON 标签，作为对外契约。
- `client.go`：基于标准库 `net/http` 的轻量 HTTP 客户端，封装对 `/api/v1/backups` 和 `/health` 的 CRUD 操作，超时默认 30s，支持注入自定义 `*http.Client`。
- `manager.go`：在 Client 之上提供带读缓存的高层 Manager，使用 `sync.RWMutex` 保护内存缓存（backups/restores/schedules），缓存有效期 30 秒，写操作后自动失效。
依赖方向单向：Manager → Client → HTTP 请求，不反向依赖上层业务逻辑。
