- 每个 API 资源独立一个 handler 文件，并在文件顶部定义对应的 JSON 结构体（如 Backup、Schedule），字段通过 json tag 暴露。
- RESTful 路由遵循 List/Create/Get/Update/Delete 命名约定，处理器函数名与 HTTP 动词一一对应（ListBackups、CreateBackup、GetBackup、DeleteBackup 等）。
- 请求体绑定统一使用 `c.ShouldBindJSON(&struct)` 并立即检查错误，失败时返回 400 及 `error` 字段。
- 响应统一通过 `c.JSON(status, payload)` 返回，Mock 场景下直接构造内联结构体并返回。
- 中间件以包级函数形式暴露（`Logger()`、`Recovery()`），在 `main.go` 中通过 `r.Use(...)` 链式挂载。
