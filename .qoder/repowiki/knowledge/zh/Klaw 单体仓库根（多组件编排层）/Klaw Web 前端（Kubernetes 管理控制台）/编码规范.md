- API 调用统一通过 `src/lib/api.ts` 中按领域命名的 axios 实例（`clusterApi`、`podApi`、`deploymentApi` 等）暴露，每个对象包含 CRUD 方法，URL 路径遵循 `/clusters/{cluster}/...` 或 `/tenants` 等 RESTful 约定。
- 所有后端响应数据结构以 TypeScript `interface` 形式在 `api.ts` 中集中声明，页面组件直接 import 对应类型，避免重复定义。
- 页面组件采用函数式组件 + Hooks 风格，统一使用 `useState` 管理 loading/error/data 三态，并通过 `useEffect` 在挂载时触发数据获取。
- 样式全部使用 Tailwind CSS 原子类，深色模式通过 `document.documentElement.classList.toggle('dark')` 切换，组件内使用 `cn()`（来自 `lib/utils.ts`）合并条件类名。
- 测试文件按 `src/__tests__/unit/` 和 `src/__tests__/integration/` 分层组织，Mock 数据与处理器放在 `src/__tests__/mocks/`，通过 `vitest.setup.ts` 初始化 MSW worker。
- Mock 模式通过 `localStorage.USE_MOCK` 持久化开关，配合 `dev:mock` 环境变量和 MSW 的 `public/mockServiceWorker.js` 实现前后端解耦开发。
