模块采用标准 Vite + React 单页应用结构：`src/main.tsx` 通过 `BrowserRouter` 和 `ToastProvider` 包裹根组件；`src/App.tsx` 集中定义路由与导航（Dashboard、Backups、Tenants、Deployments、Services、Pods、Nodes、Monitoring、Diagnostics），并内置 Mock 模式切换（`localStorage.USE_MOCK`）。数据层集中在 `src/lib/api.ts`，使用两个 axios 实例（`api` 指向 `/api`，`v1Api` 指向 `/api/v1`），按领域拆分为 `clusterApi`、`podApi`、`nodeApi`、`eventApi`、`monitoringApi`、`deploymentApi`、`serviceApi`、`analysisApi`、`alertingApi`、`backupApi`、`tenancyApi`、`auditApi`、`unifiedClusterApi`、`unifiedResourceApi` 等命名空间对象，所有 API 类型在文件内以 TypeScript interface 声明。UI 层按职责分层：`src/pages/` 为页面级组件，`src/components/` 为可复用组件（ClusterSelector、NamespaceSelector、RefreshButton、ServiceDetailDrawer），`src/contexts/ToastContext.tsx` 提供全局 Toast 通知。测试体系基于 Vitest + jsdom，Mock 数据通过 MSW（`src/__tests__/mocks/`）在 `public/mockServiceWorker.js` 中注入，支持 `dev:mock` 脚本启动 Mock 开发环境。构建产物输出到 `dist/`，Vite 代理 `/api` 到后端 `http://localhost:8080`。
