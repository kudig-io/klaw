模块由两个职责清晰的组件构成：
- `cluster.go` 中的 `ClusterOperator` 负责实际的集群资源采集与还原：通过 `kubernetes.Interface`（client-go）列举 namespaces、serviceaccounts、pods、deployments、services、configmaps、secrets、ingresses、networkpolicies、persistentvolumes、persistentvolumeclaims 等资源，经 `sanitize` 剥离敏感字段后序列化为 `BackupData` JSON 文件写入本地目录。
- `manager.go` 中的 `Manager` 作为备份元数据管理器，使用内存 `map[string][]Backup` + `sync.RWMutex` 维护按 cluster 分组的备份记录，并通过注入的 `*storage.Store` 以 JSON 形式持久化到后端存储；提供 Create/List/Get/Delete/Summary 等 CRUD 接口。
依赖方向单向：`Manager` 依赖 `storage.Store`，`ClusterOperator` 依赖 client-go，两者之间无直接耦合，仅共享 `BackupSpec`、`StorageLocation` 等类型定义。
