模块以 `kind/` 子目录为核心，采用「声明式配置 + 命令分发脚本」的轻量组合：
- `cluster-config.yaml` 使用 `kind.x-k8s.io/v1alpha4` API 声明一个名为 `klaw-test` 的集群，包含 1 个 control-plane（带 `ingress-ready=true` 节点标签、hostPort 80→8081/443→8443 映射）和 2 个 worker 节点，并通过 `extraMounts` 将宿主机 `data/` 目录挂载到各节点的 `/data` 实现持久化；网络层固定 Pod/Service 子网。
- `manage.sh` 是统一 CLI 入口，顶部集中定义 `CLUSTER_NAME`、`CONFIG_FILE`、`DATA_DIR` 等常量，通过 `case` 语句分发 `create/delete/status/export-config/deploy-sample/load-image/install-tools/check/help` 等子命令；每个子命令在执行前调用 `check_docker`/`check_kind`/`check_kubectl` 做依赖校验，失败即 `exit 1`，成功后自动 `kubectl config use-context kind-klaw-test` 切换上下文。
- `data/` 为空目录，作为容器内 `/data` 的 hostPath 挂载点，由 cluster-config 注入。
- 依赖方向单向：脚本 → kind/kubectl/docker 命令行工具，不引入任何外部库或网络资源（仅 `install-tools` 拉取 metrics-server YAML）。
- 顶层 `README.md` 同时覆盖 in-cluster Helm 部署流程（`helm upgrade --install klaw helm/klaw -f helm/klaw/values-kind.yaml`），但本模块自身只负责 Kind 集群生命周期管理。
