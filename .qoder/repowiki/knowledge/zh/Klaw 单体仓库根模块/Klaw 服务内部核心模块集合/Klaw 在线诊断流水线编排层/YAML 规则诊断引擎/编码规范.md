- 条件类型通过字符串字段 Type 区分，Engine.evaluateCondition 使用 switch 分支分派到对应 evalXxx 方法，新增条件需同时补充类型常量与处理器。
- Rule 的 Severity 字段统一通过 GetSeverity() 映射到 types.Severity，支持英文与中文别名（critical/严重、warning/警告、info/提示）。
- Loader 在 LoadFile 中对缺失字段进行默认值回填（Name 回退为 ID、Severity 默认 info、Enabled 默认 true），保证规则健壮性。
- Engine 的公开方法 Evaluate/EvaluateByCategory 均通过 select ctx.Done() 检查上下文取消，确保长时间评估可被中断。
- Metric 阈值比较通过 Operator 字段支持 gt/gte/lt/lte/eq/ne 及 >=、<=、==、!= 两种写法，Negate 字段统一反转结果。
