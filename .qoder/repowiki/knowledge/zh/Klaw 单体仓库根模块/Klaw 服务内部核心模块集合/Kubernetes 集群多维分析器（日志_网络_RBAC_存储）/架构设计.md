模块由四个相互独立的子包组成：`loganalysis`、`networkanalysis`、`rbacanalysis`、`storageanalysis`，每个子包对外暴露一个 `Analyzer` 结构体及 `NewAnalyzer` 构造函数。
- `loganalysis` 采用分层设计：`types.go` 定义 `LogAnalysis`、`LogEntry`、`SecurityEvent` 等数据结构；`analyzer.go` 实现纯文本解析逻辑（按行分类级别、提取时间戳、匹配安全事件与性能指标）；`engine.go` 通过 `kubernetes.Interface` 获取 Pod 日志流并调用 Analyzer，同时从 Pod Annotation `klaw.io/log-tail-lines` 读取 tail 行数。
- `networkanalysis`、`rbacanalysis`、`storageanalysis` 结构一致：Analyzer 持有 `kubernetes.Interface`，提供 `ListXxx` 辅助方法与一个主 `AnalyzeXxx(ctx)` 方法，一次性 List 所有相关资源（跨命名空间使用空字符串），然后聚合为带 `timestamp` 的分析结果结构体。
- 依赖方向单向向外：各 Analyzer 仅依赖 `k8s.io/client-go` 访问 API Server，彼此之间无耦合，上层通过各自包名调用。
