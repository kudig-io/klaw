internal/ 下按职责垂直切分子模块，横向通过三类共享机制协作：
- 统一持久化：storage.Store 是所有需要落地的模块（audit、backup、automation、tenancy、monitoring、ops 等）共享的 SQLite 键值文档存储，提供 JSON 序列化存取与并发安全写入，旧版 documents 表数据由迁移逻辑自动落到领域专用表。
- 统一配置：config.Config 在应用启动时加载并注入到各 Manager/Service，保证集群连接、通知渠道、分析规则等配置一致性。
- 事件驱动与消息抽象：events 监听 Kubernetes 事件后通过 messaging 抽象层（钉钉/飞书插件）推送告警，同时被 monitoring_metrics 和 alerting 复用；diag_pipeline 作为在线诊断入口编排 collector/analyzer/rca/autofix/reporter 输出结构化结果供 api/server.go 暴露。
- API 路由分层：api/server.go 集中注册所有 HTTP 处理器，将请求分发到对应业务 Manager，形成「API → Manager → 领域逻辑 → storage」的分层结构。
