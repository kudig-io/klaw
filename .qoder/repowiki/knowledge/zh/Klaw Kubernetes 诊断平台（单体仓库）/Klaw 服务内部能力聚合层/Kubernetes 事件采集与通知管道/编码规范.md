- 事件类型、资源类型、严重级别均使用 string 自定义类型配合 const 常量声明，便于类型安全匹配。
- Source 实现通过嵌入 BaseSource 复用订阅管理、过滤器和并发安全的 emit 逻辑，仅关注 Start/Stop 和资源监听。
- 并发安全通过 sync.RWMutex 保护共享状态（handlers、channels、seen 等），读多写少场景优先使用 RLock。
- 错误处理采用 fmt.Errorf 包装上下文信息并向上返回，日志输出使用 fmt.Printf 直接打印。
- Watch 循环统一使用 select 监听 stopCh 和 ResultChan，连接断开时休眠 5 秒后 goroutine 重启监听。
