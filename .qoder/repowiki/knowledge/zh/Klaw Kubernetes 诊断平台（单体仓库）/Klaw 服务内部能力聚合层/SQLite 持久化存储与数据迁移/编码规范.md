- 每个领域实体在 schema.go 中先定义 Row 结构体（含 json 标签），再实现对应的 `migrateXxx()` 方法，从旧版 `GetJSON(namespace, key, &rows)` 读取并批量 INSERT OR REPLACE 到新表。
- 布尔值在 SQLite 中以 INTEGER(0/1) 存储，通过 `boolInt()` 辅助函数在 bool 与 int 之间转换。
- 复杂字段（slice、map、嵌套结构）统一通过 `json.Marshal` 序列化为 TEXT 后存入，迁移时使用自定义 helper（`getStr`、`getStrSlice`、`getInt`、`getBool`、`getMap`）反序列化。
- SQL 查询全部使用 `?` 占位符参数化，避免字符串拼接，并通过 `fmt.Errorf("...: %w", err)` 包装错误以便调用栈追踪。
- 写操作（`PutJSON`）通过 `s.mu.Lock()/Unlock()` 加互斥锁保护，读操作不加锁，利用 SQLite 自身的事务语义保证一致性。
