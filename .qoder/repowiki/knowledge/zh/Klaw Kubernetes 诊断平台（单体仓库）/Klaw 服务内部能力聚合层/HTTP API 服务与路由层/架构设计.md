模块以 `server.go` 中的 `Server` 结构体为核心，聚合 kubernetes.Manager、monitoring.Service、alerting.Manager、backup.Manager、tenancy.Manager、audit.Logger、automation.Manager、kubernetes.Resources、metrics.Collector 等内部依赖，通过 `NewServer` 构造并在 `SetupRoutes` 中注册所有 `/api/*` 路由；`unified_v1.go` 通过 `setupUnifiedV1Routes` 将同一批 handler 同时挂载到 `/api/v1/*` 路径，实现双版本兼容。各业务域按文件拆分：`alerting.go`（告警规则 CRUD/评估/历史）、`backup.go`（备份 CRUD/摘要）、`tenancy.go`（租户与用户管理 + 审计日志查询）、`analysis.go`（Pod 日志分析、RBAC 分析）、`automation_api.go`（脚本编排与网络/存储分析）、`diag.go`（诊断入口）。请求处理统一通过 `respondJSON`/`respondError` 返回 JSON，错误经 `deprecationMiddleware` 自动为旧版 `/api/` 路径添加 Deprecation/Sunset 响应头。SPA 静态文件由 `serveSPA` 兜底返回 `./web/dist/index.html`。
