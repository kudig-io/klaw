- 每个 Collector 实现通过独立的 init() 调用 collector.RegisterCollector(NewCollector()) 完成自注册，无需显式装配。
- Collect 方法统一先 Validate(config) 再返回 types.NewDiagnosticData(mode)，并将原始文件通过 data.SetRawFile(key, content) 写入 DiagnosticData。
- Config 字段同时声明 json 与 yaml tag，并使用 New*Config 构造函数设置默认 TimeoutSeconds=60。
- 在线模式的 K8s 客户端通过带互斥锁的 getClient() 懒加载并缓存，避免重复建立连接。
- 对 K8s API 的调用使用 retryWithBackoff 封装指数退避重试，并在 context 取消时及时返回 ctx.Err()。
