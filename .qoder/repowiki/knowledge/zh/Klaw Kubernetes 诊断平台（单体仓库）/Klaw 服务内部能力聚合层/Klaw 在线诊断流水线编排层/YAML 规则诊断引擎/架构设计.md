本模块采用「数据定义 + 加载器 + 评估引擎 + 分析器适配器」四层结构：
- types.go 定义 Rule / Condition / RuleSet 三种核心数据结构，并通过 `yaml`/`json` tag 支持序列化；Rule 提供 GetSeverity 与 ToIssue 方法将规则映射到上层 types.Issue。
- loader.go 的 Loader 负责从单个 YAML 文件、目录或内置规则集（LoadBuiltin）加载 RuleSet，并在加载时做默认值填充与基础校验（ID 必填、未设置则启用等）。
- engine.go 的 Engine 持有 Loader 引用，对外暴露 Evaluate 与 EvaluateByCategory 两个入口；内部通过 evaluateCondition 递归分派到 file_contains、regex_match、metric_threshold、and、or 五种条件处理器，支持 context 取消传播。
- analyzer.go 的 RuleAnalyzer 包装 Engine，实现 analyzer.BaseAnalyzer 接口，提供 DefaultRuleAnalyzer、RuleAnalyzerFromDir、RuleAnalyzerFromFile 三种构造方式，使规则引擎可被上层诊断框架以统一 Analyzer 接口调用。
依赖方向单向：analyzer → engine → loader → types，不反向依赖外部包。
