本模块由五个相互独立的子包组成，均依赖 `internal/diag/types` 共享 Issue/Severity/DiagnosticData 等核心类型：
- `history/`：以 JSON 文件形式将每次诊断结果持久化到 `~/.klaw/history/`，通过 `Manager` 提供 Save/List/Get/Delete/Diff/CleanupOldEntries 等 CRUD 与差异对比能力。
- `notifier/`：定义 `Notifier` 接口，实现 Slack/DingTalk/WeChat Work 三种 webhook 推送，并通过 `MultiNotifier` 聚合多个通道；配置通过 `NewConfigFromEnv()` 从环境变量读取。
- `cost/`：基于默认 AWS 定价对 SystemMetrics 进行 CPU/内存/存储/网络成本估算，输出日/月/年费用及优化建议。
- `scanner/`：通过 `exec.CommandContext` 调用外部 trivy 二进制进行镜像漏洞扫描，解析 JSON 输出并统计各严重级别数量。
- `tui/`：基于 charmbracelet/bubbletea + lipgloss 构建 TUI，使用状态机（StateMenu/StateDiagnosing/StateResults/StateIssueDetail/StateHistory/StateSettings）管理界面切换，并通过 `startDiagnosis` 组合 collector 与 analyzer 执行诊断。

依赖方向单向：所有子包仅向上依赖 `types`，彼此之间无直接耦合，由上层编排调用。
