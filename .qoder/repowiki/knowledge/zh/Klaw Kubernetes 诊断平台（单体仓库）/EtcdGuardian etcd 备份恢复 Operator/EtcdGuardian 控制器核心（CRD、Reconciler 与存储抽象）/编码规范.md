- 每个 Reconciler 在 Reconcile 入口先添加 finalizer，再根据 DeletionTimestamp 走 handleDeletion 清理路径。
- 业务状态通过 Status.Phase 枚举推进，每步完成后调用 r.Status().Update 并 return ctrl.Result{Requeue: true} 触发下一轮。
- 失败路径统一通过 updateStatusFailed 设置 Phase=Failed、CompletionTime 与 Message，再返回错误。
- 可插拔后端通过 interface + NewXxxFactory 模式实现，如 storage.NewStorage 按 provider 字符串分发到 S3/OSS 等实现。
- CRD 类型集中放在 api/v1alpha1，并通过 groupversion_info 中的 SchemeBuilder.AddToScheme 注册到全局 scheme。
- 控制器方法内统一以 logr.WithValues 注入资源 NamespacedName 作为上下文日志键。
