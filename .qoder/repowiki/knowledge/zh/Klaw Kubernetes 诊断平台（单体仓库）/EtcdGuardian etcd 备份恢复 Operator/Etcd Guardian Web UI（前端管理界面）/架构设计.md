单页应用，入口为 `src/main.tsx`，使用 `@tanstack/react-query` 的 `QueryClientProvider` 包裹全局数据请求上下文；`App.tsx` 通过本地 `activeTab` state 在 Dashboard、Backups、Restores、Schedules 等页面组件间切换，未使用路由库。UI 由 `src/components/` 下的功能组件（Dashboard、BackupList/Create、RestoreList/Create、ScheduleList/Create、Layout）组成，并通过 `components/index.ts` 统一导出。样式采用 Tailwind CSS（`tailwind.config.js`），构建产物由 `vite.config.ts` 配置别名 `@` 指向 `src`。部署时静态资源由 Nginx 托管（`nginx.conf`），`/api` 路径被反向代理到上游 `backend:8080`，其余静态资源启用一年缓存与安全响应头。`api/`、`store/`、`pages/` 目录当前为空，预留了后续拆分 API 客户端、状态管理与页面级组件的空间。
